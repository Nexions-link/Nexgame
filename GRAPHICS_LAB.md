# NexGame Graphics Lab — независимый визуальный прототип

## Статус
- База: NexGame Alpha 0.3.5.26 (исходная логика игры и базовая 3D-сцена).
- Ветка: `graphics-prototype`.
- Имя отдельной сборки: **NexGame Graphics · Preview 0.1.0**.
- Основная NexGame в ветке `main` не изменена.
- Все ключи сохранений, графических настроек, камеры, имени и развёрнутой группы имеют префикс `nexgame-graphics-`; прогресс основной игры не считывается и не перезаписывается.
- `online-config.js`: `WORLD_WS_URL=''`. Тестовая графическая версия работает в одиночном режиме и не соединяется с боевым Render-сервером NexGame.
- Это отдельный эксперимент: изменения графики не следует переносить в `main` до отдельного решения и проверки на iPhone.

## Публикация как отдельный GitHub Pages (разные ссылки)

Чтобы создать отдельный репозиторий, когда доступен интерфейс GitHub:

1. Перейди на https://github.com/new/import
2. Источник: `https://github.com/Nexions-link/Nexgame.git`.
3. В качестве назначения укажи пользователя `Nexions-link` и новое имя **`Nexgame-Graphics`**; видимость **Public**. Начни импорт и дождись окончания.
4. В новом репозитории открой `Settings → Pages → Build and deployment`, выбери `Deploy from a branch`; **Branch: `graphics-prototype`**, папка `/(root)`, затем **Save**.
5. Дождись GitHub Pages. Ожидаемая ссылка после успешной публикации: `https://nexions-link.github.io/Nexgame-Graphics/`.

Важно: не выбирай `main` источником GitHub Pages нового репозитория, иначе это будет исходная игровая версия с подключением к тому же Render.
Импорт репозитория клонирует историю и ветки Git (на всякий случай проверь, что ветка `graphics-prototype` доступна в выпадающем списке).
Если GitHub потребует разрешить доступ коннектору к новому репозиторию, настрой это отдельно.

## Дальнейший графический эксперимент
1. Безопасный вертикальный срез: лагерь Нараче, один герой-таурен, долгоног, участок травы и два-три дома.
2. Более качественные самостоятельные 3D-модели в формате `.glb` с лицензиями, разрешающими использование в игре.
3. Новые текстуры и материалы, закатное освещение, оптимизация LOD и WebGL под iPhone.
4. Графические пресеты и оценка FPS/памяти Safari. Реальные результаты измерять на устройстве.
5. После одобрения пользователем — адресный перенос нужных графических компонентов в основную NexGame.

При необходимости вернуть старый вид просто открой основную ссылку NexGame. Она не зависит от экспериментальных изменений.
