# NexGame — единый онлайн-мир (этап 1)

## Что уже работает в коде
- Отдельный сервер `server/index.js` на Node.js + WebSocket (`ws`).
- **Один мир `mulgore`, без создания комнат**. Все подключения к одному процессу видят один список игроков.
- Сетевой цикл 10 раз в секунду, сглаживание удалённых моделей на клиенте.
- Подключение/переподключение, отключение, имя, положение и направление персонажа; ограничение до 100 соединений для прототипа.
- Существующие одиночные сохранения, задания и управление iPhone остаются работоспособными.
- Если `WORLD_WS_URL` пустой, игра работает без сети в одиночном режиме.

## Запуск локального сервера
Нужны Node.js 20+ и npm.

```bash
cd server
npm install
npm start
```

Проверка работоспособности: `http://localhost:3000/health` (показывает количество подключённых игроков).

Для разработки в локальной сети укажите адрес WebSocket в `online-config.js`:
```js
export const WORLD_WS_URL='ws://192.168.1.10:3000';
```

**Важно:** GitHub Pages открывается через HTTPS и требует **wss://**, а не **ws://**. Для публичного запуска разместите `server/` на хостинге Node.js с постоянным работающим процессом и TLS/WSS через хостинг или reverse proxy; запишите адрес в `online-config.js`, например `wss://world.example.com`. Сам GitHub Pages WebSocket-сервер не запускает.

Для ограничения WebSocket-подключений с неизвестных сайтов установите переменную окружения `ALLOWED_ORIGINS`, например `https://nexions-link.github.io`; несколько origins перечисляются через запятую. `PORT` задаётся хостингом или по умолчанию 3000.

## Сетевой протокол, версия 0 (JSON)
Клиент → сервер:
- `{"type":"join","name":"Странник","x":0,"z":10,"yaw":3.14,"level":1}`
- `{"type":"move","x":1,"z":9,"yaw":3,"moving":true,"level":1}`

Сервер → клиент:
- `{"type":"welcome","id":"...","world":"mulgore","tickMs":100,"players":[]}`
- `{"type":"snapshot","players":[{"id":"...","name":"Странник","x":0,"z":10,"yaw":3.14,"moving":false,"level":1}]}`
- `{"type":"leave","id":"..."}`

## План следующих этапов
1. **Этап 1 — сетевое присутствие (текущий код):** подключение, отображение других игроков, плавные движения. Требуется развернуть сервер и проверить на двух устройствах.
2. **Этап 2 — авторитетный сервер перемещения:** сервер хранит постоянные учётные записи и ID героев; вход по токену, проверка скорости, коллизий и реконнектов; дистанционные игроки не должны «телепортироваться» через стены.
3. **Этап 3 — общий PvE:** мобы, здоровье босса, агро и боевые таймеры исполняются на сервере; клиенты посылают команды «атаковать» вместо готового урона.
4. **Этап 4 — сохранения:** серверная база PostgreSQL с инвентарём, заданиями, валютой, транзакционной выдачей лута. Миграция с localStorage после подтверждения игроком.
5. **Этап 5 — масштабирование:** зоны интереса (AOI), пространственная фильтрация снапшотов, несколько процессов/зон, мониторинг и античит.

## Ограничения и безопасность
Это **не полноценная MMORPG**, а первый интеграционный прототип. Сейчас все мобы, урон, лут и инвентарь остаются **локальными** для каждого браузера. Сервер пока доверяет имени и начальному положению от клиента; он не предоставляет авторизацию, серверные сохранения и защиту от читов. Не использовать для экономики и соревновательного игрового мира до этапов 2–4.

Пока сервер не развёрнут, индикатор `Мир: одиночный` — нормальное поведение.
