# NexGameWorld — G-02: запись реальных кадров и сравнение выпусков

**Проект:** NGW-ART-REMASTER-001 · **Ракурсы:** R1 / G-01  
**Реализация:** `planet-test/visual-capture.js`, `planet-test/planet.js`, `planet-test/index.html`  
**Статус визуальной приёмки:** определяется отдельно после просмотра кадров из браузерной игры.

## Что можно сделать в игре

1. На iPhone открой **Настройки → Качество графики → G-01 · Эталонные ракурсы R1**.
2. Выбери **Высокое**, контрольный ракурс, нажми **Открыть ракурс R1**.
3. Нажми **Сохранить «До»** для базового изображения текущей сборки.
4. После обновления игры выбери **тот же ракурс и пресет** на том же телефоне, нажми **Сохранить «После»**.
5. Нажми **Сравнить кадры «До / После»**. Передвигай ползунок, который накладывает части двух реальных WebGL-кадров друг на друга.
6. Нажми **Закрыть** для возврата к игровому HUD, затем **В игру**, чтобы восстановить обычный ракурс персонажа без изменения серверной позиции.

Снимки `До` и `После` сохраняются **отдельно для каждого из четырёх G-01 ракурсов**, по два изображения на точку. При повторном сохранении того же слота старый кадр этого слота заменяется. Данные находятся в IndexedDB браузера `ngw-art-compare-v1` исключительно на устройстве; другие браузеры и устройства их автоматически не видят. При очистке данных сайта сохранённые снимки могут исчезнуть, а в приватном режиме Safari хранилище может быть недоступно — интерфейс сообщает об ошибке.

## Что записывает каждый снимок

- Версия сборки из `data-build` (не нарисованная строка R1)
- ID ракурса G-01 и название локации
- Пресет графики: economy/balanced/high
- Нормаль сферы и фактическое положение и точка фокуса временной контрольной камеры
- Угол обзора FOV, фактические ширина/высота видимой области, DPR
- Средние FPS и P95 интервала между кадрами за время нахождения в режиме R1 — если накоплены валидные измерения
- Время снимка в UTC
- Действительные пиксели 3D-сцены, прочитанные из изолированного WebGLRenderTarget, сохранённые в PNG

Данные аккаунта, логин, пароль, идентификаторы игроков, координаты **игрового персонажа**, прогресс, чат и сетевые события не сохраняются в фотографиях или метаданных. Движения чужих игроков на самой сцене могут быть видны как обычная картинка, поэтому снимки не отправляются в сеть автоматически. UI и открытые панели не включаются в изображение: захватывается исключительно визуальная сцена игры, соответствующая цели графического ремастера.

## Технические гарантии

- Существующая штатная игровая камера НЕ меняется: G-02 использует только добровольно включаемую контрольную камеру G-01.
- Съёмка осуществляется по команде с кнопки, один дополнительный offscreen рендер и чтение RGBA-буфера. Постоянно включать `preserveDrawingBuffer` не требуется.
- Размер PNG ограничен максимальным ребром 1280 px при **сохранении исходных пропорций**. Никакого искусственного растягивания до 9:16.
- Буфер снимка переворачивается из нижне-ориентированного WebGL в обычную ориентацию Canvas. Обязательное восстановление предыдущего render target в `finally`.
- Изображения принадлежат тому же браузерному origin, в котором открыта игра, и записываются через IndexedDB без внешних запросов, облака и синхронизации.
- Сравнение предупреждает о разных камерах, пресетах, FOV или размерах экрана. Оно не выдумывает процент «сходства».
- HUD остаётся живым за оверлеем. Закрытие сравнения не удаляет UI и не изменяет аккаунт/сохранения.
- Отдельная визуальная приёмка настоящего кадра в Safari на iPhone нужна после автоматического CI; автоматические тесты не доказывают отсутствие ошибок GPU/рендера на конкретном телефоне.

## Как интерпретировать результаты

- **G-02** доказывает, что мы можем получать и сопоставлять реальные кадры двух сборок при повторяемой позиции камеры.
- **R1** — отдельно предоставленное изображение, использующееся как художественный ориентир. Сравнение с R1 — визуальное, человеком, по карте признаков в `NGW_VISUAL_REFERENCE_R1.md`.
- Процентного совпадения с R1 нет, поскольку генеративный референс не является физически воспроизводимым render target. Нельзя объявлять ремастер завершённым по исходному G-02 снимку.

## Приёмка G-02

1. Запускается сферическая игра с аккаунтом, без ошибок новых модулей.
2. Из всех четырёх контрольных точек можно сделать PNG в high и другие пресеты.
3. Сохранённый `До` остаётся после закрытия вкладки/перезагрузки и установки новой игры на том же origin (при доступности IndexedDB).
4. Разделитель показывает именно две реальные сохранённые картинки, изменяя только область видимости верхней.
5. При различии размеров или графических настроек интерфейс честно предупреждает пользователя.
6. Кнопка закрытия возвращает к HUD, а кнопка «В игру» — к существующей штатной камере.
7. Регрессионные тесты и релизный шлюз из AGENTS.md пройдены. Ручное тестирование iPhone и визуальная художественная приёмка фиксируются отдельно.
