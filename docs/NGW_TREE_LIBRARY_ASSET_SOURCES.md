# NexGameWorld — происхождение материалов библиотеки деревьев

## T1 — tree_pine_ancient (23.10.2026)
- **Авторство:** самостоятельная процедура NexGameWorld, код `planet-test/tree-library-ancient-pine.js`.
- **Лицензированные внешние текстуры/модели:** отсутствуют.
- **Геометрия:** Three.js Cylinder/BufferGeometry для рельефного ствола, сплайновых сегментов корней и ветвей; новые наборы трёхмерной хвои и мха; воспроизводимы из фиксированного seed.
- **Карты:** `bark_pine_old` — albedo (sRGB), normal (linear), roughness (linear), height (linear); исходная математическая процедура `oldPineBarkSample`. 1024 × 2048 для тестового просмотра; мастер-алгоритм допускает более высокие разрешения без привлечения чужого исходника.
- **Объект размещения:** первый существующий `ART_LAB.treeSites[0]` сферического Сада Каменного ветра, без физических коллизий; старый прототип сохранён для сравнения.
- **Геймплей:** основной клиент, квесты, сервер, лесные моби, коллайдеры не изменены.
- **Контроль:** `planet-test/tests/tree-library-ancient-pine.test.mjs`.

## T2 — четыре дополнительные оригинальные породы (23.10.2026)
- **Авторство:** NexGameWorld procedural originals, файл `planet-test/tree-library-forest-types.js`; ни один материал, рисунок, mesh или shader из других игр не извлекался.
- `tree_oak_whispering`: `bark_oak_ancient`, широкая изломанная крона `leaf_oak`, объёмные трещины и корни.
- `tree_dead_sentinel`: `wood_dead_weathered`, надломленная/полая древесина без листьев, скелетные ветви.
- `tree_broadleaf_moss`: `bark_wet_moss`, тёмная `leaf_dark`, выраженный 3D мох.
- `tree_root_ancient`: `root_wood`, увеличенные изогнутые корни и ствол, неравномерная `leaf_dark`.
- **Карты:** albedo (sRGB), normal / roughness / height (linear), в памяти генерируются по одной воспроизводимой оригинальной функции на вид; разрешение задаётся параметром `mapSize`. Исходники — математические алгоритмы, сторонние модели отсутствуют.
- **Варианты:** по три формы `variation=0/1/2` на разных seed. Модель основана на реальных 3D-поверхностях и не использует обманный плоский задник.
- **Использование:** только независимая художественная галерея, без коллизий, мультиплеерных изменений и новых систем хранения.
