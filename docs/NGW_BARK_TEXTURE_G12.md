# NGW-ART-REMASTER-001 — G-12: оригинальная глубокая кора

Исходная версия 0.6.45.39, цель 0.6.45.40.

- Три периодически бесшовных RGBA карты 256×512: albedo в sRGB, рельеф и шероховатость в linear. Тёмные продольные расщепления, поперечные трещины, неровные волокна, мох в углублениях.
- Уменьшено повторение UV по вертикали с 7 до 4; никакие чужие ассеты не импортированы.
- Стволы, верхние ветки и 34 поваленных бревна используют один общий атлас; индивидуальная цветовая градация хвойных, лиственных и сухой древесины — в InstanceColor, без дополнительного меша.
- Economy и preview только с albedo; balanced с bump; high с bump и roughness. При ошибке генерации — непрозрачная запасная древесина.
- Штатная камера, рельеф, сеть, коллизии и 400 древних деревьев не меняются.
- G-12 тесты плюс общий CI, после релиза — ручное сравнение реальных iPhone кадров R1 и FPS.
