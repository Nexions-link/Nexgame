## Правила обновления
- Статусы: NOT_STARTED / IN_PROGRESS / TESTING / PUBLISHED / BLOCKED.
- После каждого реального изменения фиксировать дату, SHA коммита, действующую игровую версию, ссылку прямой проверки и результаты автоматических/ручных тестов.
- Сообщения об успешном коммите или CI не заменяют проверки фактического сайта.
- Не ставить PUBLISHED, пока не открывается сцена и не загружаются необходимые ассеты.
- Замечания от владельца заносить ниже с датами и состоянием выполнения.

## Замечания и уточнения
- 23.10.2026: приоритет — максимально качественная графика деревьев; не оптимизировать заранее под iPhone/FPS.
- 23.10.2026: пользователь занимается только тестированием и даёт художественные наводки; технические решения принимает ассистент при работе над задачей.

## Ход работ 23.10.2026 — пилот T1
- Проверен `Nexions-link/Nexgame/main`, текущая версия и цепочка публикации GitHub Pages → Nexions-portal → nexions.ru.
- Разработаны собственные мастер-алгоритмы древесины (скульптурная геометрия, карты albedo/normal/roughness/height), 9 корней, многоярусные первичные и вторичные ветви, 3D хвоя, фактурный мох.
- Геометрия корней/ветвей объединяется **без потери деталей**, чтобы не увеличивать draw calls на каждый сегмент.
- Смена модели работает только в независимом Саду Каменного ветра, не меняет сохранения, многопользовательский сервер и лесные коллизии.

- Первый CI выявил два устаревших утверждения об идентификаторе страницы и параметре скрипта; тесты поправлены. Повторная проверка пройдена после синхронизации номера сборки с сервером.
- Итог: CI клиента/сервера/нагрузки успешно пройден, зеркало и версия на Nexions.ru подтверждены production-аудитом. Тестирование реального WebGL-рендера и художественная приёмка на устройстве владельца остаются открытыми; поэтому статус T1 — TESTING.

## T2 — разработка библиотеки (23.10.2026)
- Добавлены оригинальные скульптуры `tree_oak_whispering`, `tree_dead_sentinel`, `tree_broadleaf_moss`, `tree_root_ancient`, исходная `tree_pine_ancient` оставлена пятой сравниваемой моделью.
- Все пять пород независимо выбираются на одной сферической сцене. До/после переключает старые деревья и новые при неизменных посадочных координатах; формы I/II/III детерминированы параметром `variation`.
- Для каждой из четырёх новых пород реализованы независимые оригинальные PBR-процедуры: albedo, normal, roughness, height; настоящие объёмные корни/ветви/листва. Сухой страж получил полый сломанный верх.
- Для пилотной сосны добавлена посадка корней по перепадам `artLabHeight` и увеличена читаемость хвои.
- Пройдены CI клиента/сервера/нагрузки на исходной галерее (коммит `9164756dc2cbe6a0750650ae57182c0f1fbed667`). Публикационный коммит `82c9c11e879f6488c3b66521cbcdea09d5db7483` прошёл итоговый production-аудит Nexions.ru, Render и зеркала.
- Работы не меняют авторитетные игровые серверные правила, игровой Шепчущий лес, NPC, физику, инвентарь и прогресс.
