# Завершение переноса NexGame в сферический мир

Рабочий план от **16 октября 2026**. База аудита: `main`, коммит
`ed1adfb447cebedeee7a5f5fe69b9c659fa3ac50`, **PT 0.6.2**.
На постоянном адресе `https://nexions-link.github.io/Nexgame/planet-test/version.json`
при проверке также опубликована версия 0.6.2.

Цель: перенести фактически работающие одиночные механики, модели, анимации,
интерфейс и графику основной NexGame с корректной геометрией сферы. Работа идёт
в `planet-test/`; будущий перевод основной ссылки — завершающий шаг.
Мультиплеер, группы, сетевой чат и серверный общий сундук сейчас вне объёма.
Локальный сундук на 18 мест остаётся частью переноса.

Этот документ заменяет старые оценки полноты из PROGRESS.md и исторических разделов
AUDIT.md/PORTING.md. Наличие реализации, проверка логики и визуальная приёмка —
разные состояния. Процент готовности без приёмочных сценариев не назначаем.

## Подтверждённые различия с основной игрой

| ID | Область | Различие и источник |
|---|---|---|
| C1 | Хват | В game.js/animateTauren правая кисть имеет базу −π/2, левая π, затем добавляются тюнер и анимация. В offline-rpg.js/updateEquipmentVisuals правая начинает с tuner.handX, левая с нуля; tauren-animation.js сохраняет именно эту базу. Нужна сверка матриц и изображения |
| C2 | Поступь | Main: попадание через 0,36 с, завершение через 0,75 с. Sphere: урон/оглушение сразу, визуальный импульс 0,55 с |
| C3 | Ярость/манекен | Main даёт 12/8/3 за автоатаку/рубящий/поступь, включая манекен. Sphere даёт мобам 12 за любой удар, ветка манекена завершается до начисления; поступь перебирает только mobs |
| C4 | Сближение/удары | getApproachTarget работает только через autoplay; рубящий удар издали отказывает. Auto/special могут создавать независимые pendingHits и перезаписывать одну анимацию. Отличаются округление урона и дальность на кадре попадания |
| C5 | Экипировка | Sphere разрешает надеть/снять броню и щит в бою; надевание выносливости добавляет HP. Main запрещает смену всего кроме оружия в бою и лишь ограничивает HP новым максимумом |
| R1 | Опыт | Main: 100+(level-1)*50; sphere: level*100. На 2-м уровне 150 против 200. Восстановление уровня ограничено 60 в main и 30 в sphere |
| R2 | Старт | Main: надетый топор, 0 монет, 2 настоя. Sphere: топор в сумке, 30 монет, 3 настоя. Выравнивать новые персонажи без обнуления существующих |
| R3 | Лут | rollEquipmentLoot общий, но sphere всегда выдаёт перо и отдельный ролл beak/down. В main материалы имеют отдельный 72% шанс, включают charm; возможны пустые тела |
| R4 | Торговля | Main: покупка/продажа, последние 12 позиций выкупа, фильтры, дистанция canTrade. Sphere: только покупки |
| R5 | UI | Нет полного предпросмотра героя/сравнения вещей, тюнеров, настройки имени и resetWorld. «В начало» сбрасывает положение, это не сброс RPG |
| R6 | Слоты | Main показывает 10 слотов экипировки, включая плечи; sphere — 9. Четыре места под будущие сумки main подготовлены, сами добываемые сумки ещё НЕ реализованы |
| W1 | Ноги | Main учитывает высоту под каждой стопой; сферический IK использует локальное ровное основание. Нужны отдельные точки опоры на кривой поверхности/склонах |
| W2 | Декорации | canWalkCamp проверяет заданные объекты лагеря/скалы; процедурные леса и декорации planet.js/instanceLayers не входят в этот реестр |
| W3 | AI | Мобы двигаются в x,z стартовой карты с проверкой одной следующей точки через canWalkCamp; герой уже использует sphericalSlideStep и проверку брода |
| W4 | Размер | При R=261 и скорости 4,05 м/с номинальный круг ~405 с (6:45); исходная цель ~135 с (2:15) соответствует R=87. Это расчёт без препятствий, не фактический замер |

## Порядок завершения: этапы 1 → 2 → 3

**PT 0.6.4:** улучшена смерть долгоногов: переход из текущей Walk/Peck-позы

целочисленный урон на кадре попадания, дальность 3.45 м, сближение heavyStrike

реальный offline-rpg с DOM-адаптером, читают пять GLB и проверяют локальные
преобразования при радиальных поворотах. Отдельный Planet Test CI запускается
для planet-test/**. Блок спереди/сзади и очистка после смерти также проверены.
Существующий npm test основной игры прошёл; её код не менялся.
Это логическая/геометрическая проверка, не визуальная приёмка Safari или FPS.
Настройка тюнеров через интерфейс остаётся в этапе 2; сферический IK стоп,
долгое преследование и визуальное сравнение поз остаются впереди.

## Проверки этого аудита

- Получена актуальная main; version.json GitHub Pages сообщает PT 0.6.2.
- После установки штатных devDependencies команда npm test прошла. Это проверки основной игры, НЕ подтверждение полноты sphere.
- Все 22 JS-файла верхнего уровня planet-test прошли node --check; отсутствующих относительных JS-импортов в них не найдено.
- Структура пяти GLB оружия/щитов и GLB долгонога читается; у долгонога Idle/Walk/Peck. Отображение в WebGL этим не проверено.
- Реальный Safari на iPhone, FPS и визуальное сравнение в этом аудите не проверялись.

После группы исправлений: изменения → тесты → атомарный коммит → новая PT-версия
для видимых изменений → проверка Pages → обновление чек-листа. Документационный
аудит не увеличивает игровую версию. Основную игру и сервер ради теста не менять;
общие правила переиспользовать без изменения поведения main.
