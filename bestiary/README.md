## Долгоног №001 — оригинальная модель v0.1

Здесь используется **оригинальный GLB из чата «Работа»**, предоставленный в архиве `nexgame-dolgonog-v01.zip`, а не процедурная реконструкция. Файл: [models/dolgonog-v0.1.glb](./models/dolgonog-v0.1.glb).

- 365 768 байт / 357 КБ; 3 226 треугольников; 12 мешей; один материал с цветами вершин.
- Анимации: `Idle`, `Walk`, `Peck`.
- SHA-256: `4aa3ba4e948fbc8234583ea04c6d0409fd272655594d9dca4f456b10632a56da`.
- Git blob SHA-1: `32c3264fd2a0b7b309773683d2363fc9fd86c07c`.

## Мастерская

`main.js` автоматически загружает GLB, проигрывает родные анимации, позволяет менять размеры и цвета оригинальных частей, сохранять настройки локально и экспортировать редактированный GLB с анимациями. `original-edits.js` поддерживает исходные interleaved-атрибуты и не изменяет каналы анимаций `Body.scale` и `Head.rotation`.

Для публикации выбранных правок во всех браузерах нужно внести параметры в код через GitHub. Импорт другого файла через браузер не отправляет его на GitHub. `dolgonog.js` — резервная реконструкция на случай ошибки загрузки оригинала.

Основная игра `game.js` не изменена.
