## 001 · Долгоног

Единственная актуальная модель — **авторский оригинал v0.1** из архива пользователя.
Файл: [models/dolgonog-v0.1.glb](./models/dolgonog-v0.1.glb).

- 3 226 треугольников, 365 768 байт, 12 мешей, один материал с цветами в вершинах.
- Три исходные анимации: `Idle`, `Walk`, `Peck`.
- SHA-256: `4aa3ba4e948fbc8234583ea04c6d0409fd272655594d9dca4f456b10632a56da`.

В бестиарии можно вращать модель на iPhone, переключать анимации, менять параметры внешности и сохранять локальный черновик. Скачивание GLB доступно в разделе файлов. Изменения в бестиарии не применяются автоматически к игровым существам — для публикации нужно обновить модель в GitHub.

## Использование оригинала в основной игре

Клиент `game.js` загружает модель по тому же пути из папки бестиария, используя `plainstrider-model.js`.

- Геометрия и материалы подгружаются **один раз** и разделяются между экземплярами долгоногов.
- Каждый долгоног имеет свой AnimationMixer для анимаций ожидания, ходьбы и атаки клювом.
- **Грозоклюв** использует тот же GLB с исходным игровым увеличением 1.8×.
- Характеристики, AI, позиции появления, серверная синхронизация и таблицы лута не изменены.
- В случае ошибки загрузки GLB остаётся старая упрощённая геометрия как технический резерв, чтобы мир не оказался пустым.

Для новых видов используем отдельные записи каталога и новые GLB, не меняя существующий оригинал.
