# NexGame · Бестиарий

Постоянная мастерская существ: [nexions-link.github.io/Nexgame/bestiary/](https://nexions-link.github.io/Nexgame/bestiary/)

Здесь можно вращать 3D-существо, включать анимации, менять пропорции и расцветку, а также экспортировать получившуюся геометрию в GLB. Настройки сохраняются **локально в браузере**. Для переноса выбранного варианта в общую версию скопируйте параметры редактора и передайте их в чат; затем они добавляются в исходники GitHub.

## Долгоног · 001 / v0.1

Существующий сайт модели: [архив просмотра](https://nexgame-dolgonog.brinyflea128.chatgpt.site/).

**Важно:** исходный `dolgonog.glb` с отдельного сайта пока не доступен в инструментах GitHub и Library. Поэтому здесь использована **процедурная реконструкция** по сохранённому описанию (охристое оперение, тёмные крылья, терракотовый хохолок). Это не побайтовый перенос и не оригинальная геометрия. На странице есть импорт пользовательского `.glb`, но он **не публикует** файл на сервере. Когда оригинальный GLB появится, поместить его в `bestiary/models/dolgonog-v0.1.glb` и подключить через GLTFLoader в `main.js`; модель и анимации будут доступны всем.

## Архитектура

- `catalog.js` — реестр видов, метаданные и правила черновиков.
- `dolgonog.js` — независимый параметрический прототип модели и три анимации.
- `main.js` — 3D-сцена Three.js, управление камерой, редактор, импорт/экспорт GLB.
- `index.html`, `style.css` — отдельная адаптивная страница без зависимостей от клиента RPG.
- `../tests/bestiary.test.mjs` — проверка структуры бестиария.

Реализация не импортирует `game.js`, не меняет сохранения и сетевую механику основной NexGame. Для новых существ добавляйте запись в `catalog.js` и отдельный модуль модели.
