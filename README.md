# NexGame · Мулгор

Браузерная 3D RPG от третьего лица. Alpha 0.2.2: один игровой персонаж — таурен-воин, стартовая долина в духе Мулгора и лагеря Нараче. Процедурные модели, рельеф и текстуры; два первых задания. Мелкое озеро проходится по дну; дружественные NPC не блокируют передвижение.

## Играть

https://nexions-link.github.io/Nexgame/

- WASD / стрелки или сенсорный джойстик — передвижение.
- Перетаскивание свободной области справа — вращение камеры.
- Ползунок «Камера» или колёсико мыши — расстояние до героя.
- Переключатель «Следовать за героем» — плавное горизонтальное следование камеры за поворотами персонажа. Наклон остаётся прежним; после ручного вращения камера плавно возвращается за спину. Направление движения не закручивается вместе с камерой.
- 1 / пробел — удар топором; 2 — громовая поступь; 3 — лечебный настой.
- E — разговор или предмет; I — рюкзак; Esc — пауза.
- Клик по существу / Tab — выбор цели. Удар также выбирает ближайшее существо в пределах досягаемости.

## Реализация

- `index.html` — интерфейс; `style.css` — адаптивное оформление; `game.js` — мир и игровые системы.
- Three.js 0.160.1 загружается из jsDelivr. Нужны интернет и WebGL.
- Анимация суставов вычисляется в коде: постановка копыт на рельеф, перенос веса, дыхание, замах и восстановление. Движение ног привязано к фактическому пути.
- Неподвижные детали объединены по материалу, трава использует instancing, разрешение рендера ограничено DPR 1.5, интерфейс и миникарта обновляются отдельно от кадров сцены.
- Прогресс этой долины хранится локально в `nexgame-mulgore-alpha02`. Дистанция камеры — в `nexgame-real3d-camera-distance`, автоследование — в `nexgame-real3d-camera-follow`. Старый прогресс не перезаписывается.
- Для локального запуска: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
