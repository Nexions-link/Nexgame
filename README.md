## Архив плоского прототипа

Первоначальная плоская NexGame/Mulgore (серия Alpha 0.3.x) переведена в **исторический прототип**, дальнейшая разработка и публичный запуск прекращены. Снимок сохранён в ветке `archive/flat-prototype-0.3.7.1`. Эта ветка **не является приватной**: GitHub показывает историю публичного репозитория. Она не используется GitHub Pages для запуска прототипа.

Из действующей ветки `main` убраны старые игровые страницы и исторические версии. Старые ссылки открывают сферическую игру. Утилиты, модели и общие игровые модули, используемые сферической сборкой, сохранены.

При необходимости **полностью закрыть доступ к коду** архива перенесите архивную ветку в отдельный приватный репозиторий GitHub; одна лишь архивная ветка публичного репозитория не обеспечивает конфиденциальность.

## Публикация

Изменения в `Nexgame/main` зеркалируются через GitHub Actions в `Nexions-portal/nexgameworld/`. Сайт публикует только активный сферический клиент и необходимые общие ресурсы. Архивные сборки и старый плоский вход в зеркальную публикацию не входят.
